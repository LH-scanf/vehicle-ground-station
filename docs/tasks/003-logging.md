# 任务 003：基础日志与运行记录

## 目标

建立同时服务操作员运行记录和开发维护诊断的结构化日志系统。展示范围不代表登录角色或访问权限。

## 范围

- 统一日志等级、类型、事件名和展示范围
- 时间、模块、消息、车辆编号、命令编号和扩展详情字段
- 每日本地 UTF-8 JSON Lines 文件
- 专用线程顺序写入日志，避免磁盘 I/O 阻塞界面
- 配置日志目录、保留天数、最低等级和最大界面条数
- 启动时清理超过保留期的日志文件
- 前端运行记录列表
- 等级、类型、技术详情和关键字筛选
- 清空当前显示和打开日志目录
- 记录程序启动、退出、配置加载和配置保存事件

## 不记录

- 高频车辆遥测
- 完整地图和路径数组
- 每一帧原始 WebSocket 数据
- 密码、令牌、密钥和其他敏感信息

## 暂不实现

- 指定时间段导出
- 日志压缩
- SQLite 日志数据库
- 完整遥测录制与回放
- 登录、用户角色和权限管理

## 验收条件

1. 日志按日期写入有效 JSON Lines 文件。
2. 文件写入和过期清理不在 QML 主线程执行。
3. 默认界面只显示 `primary` 记录。
4. 开启技术详情后可以显示 `diagnostic` 记录。
5. `file_only` 记录不进入前端列表。
6. 清屏不删除磁盘日志。
7. 构建、单元测试和 QML 启动检查通过。
