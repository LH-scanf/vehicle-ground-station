# 005 — 模拟遥测与状态可视化

## 目标

使用ROS侧独立开发模拟器验证`ROS Topic → vehicle_gateway → WebSocket → VehicleState → QML`完整遥测链路，并在状态总览页直接观察解析结果。

## 范围

- ROS开发模拟器发布`/odometry/filtered`、`/gps/fix`和`/rc/channels`。
- 模拟位置、航向、速度和经纬度连续变化，RC链路保持新鲜。
- Windows状态总览显示x、y、航向、RC链路、通信超时、错误码和最近遥测时间。
- 航向显示由C++将协议弧度值归一化到`[0, 360)`度；协议中的权威值仍为弧度。

## 边界

- 模拟器仅用于开发联调，不是生产数据源，不进入Windows应用。
- 不模拟或解除急停，不伪造实际模式、电池和车辆错误。
- 不实现地图、轨迹、导航、模式切换或控制命令。
- 不修改V1线上消息结构。

## 验收

- 启动ROS网关与模拟器后，地面站保持在线。
- x、y和航向连续变化，速度与模拟参数一致。
- RC链路显示正常，GPS显示有定位。
- 停止模拟器超过3秒后，地面站显示遥测过期；恢复模拟器后自动恢复在线。
- Windows构建、车辆状态测试、WebSocket集成测试和QML smoke-test通过。
