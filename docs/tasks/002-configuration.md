# 任务 002：配置管理

## 目标

实现可测试的配置加载和保存，并让设置页面能够编辑首批连接参数。

## 范围

- 共享默认配置 `config/default_config.json`
- 本地 `config/local_config.json` 按字段覆盖默认值
- 车辆 IP、端口、车辆编号、自动连接和自动重连
- JSON、IP、端口和必填字段校验
- 使用 `QSaveFile` 原子保存本地配置
- 设置页面加载、编辑、保存和错误提示
- 默认值、覆盖、损坏文件和保存行为测试

## 不在本任务范围内

- 建立 WebSocket 连接
- 心跳和自动重连行为
- 保存日志、地图或控制参数
- ROS2 与车辆网关实现

## 验收条件

1. 无本地配置时使用共享默认值并正常启动。
2. 本地配置只覆盖出现的有效字段。
3. 损坏的本地配置不导致程序退出。
4. 无效 IP、端口或车辆编号不能保存。
5. 设置页面可以保存有效配置。
6. 构建、单元测试和 QML 启动检查通过。
